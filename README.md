# Medieval Magic Quest

Medieval Magic Quest is a Minecraft plugin that adds classic medieval magic and RPG elements to your Minecraft server. This plugin is designed to enhance your Minecraft experience with a focus on long, engaging adventures, featuring magic, guilds, skills, and a shop system. It is optimized for performance and compatibility with the latest Minecraft versions.

## Install

1. Download the plugin JAR file from the releases section of this GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Join your Minecraft server.
2. Use the following commands to interact with the plugin:
   - `/rpg info`: Get information about the RPGModpack.
   - `/rpg ajuda`: Get help about the RPGModpack.
   - `/magia listar`: List available spells.
   - `/magia aprender <feitiço>`: Learn a spell.
   - `/habilidades listar`: List available skills.
   - `/habilidades evoluir <habilidade>`: Upgrade a skill.
   - `/guildas criar <nome>`: Create a guild.
   - `/guildas convidar <jogador>`: Invite a player to your guild.
   - `/guildas listar`: List available guilds.
   - `/loja comprar <item>`: Buy an item from the shop.
   - `/loja vender <item>`: Sell an item to the shop.
   - `/loja listar`: List available items in the shop.
